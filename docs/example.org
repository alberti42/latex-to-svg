* Getting started

Open this file and turn the previews on with =M-x org-latex-to-svg-mode= (or add =(add-hook 'org-mode-hook #'org-latex-to-svg-mode)= to your init).  It needs the [[https://github.com/alberti42/emacs-latex-to-svg][latex-to-svg]] engine on your ~load-path~, plus =latex= and =dvisvgm=.

While the mode is on, =C-c C-x C-l= (=org-latex-to-svg=) toggles the fragment at point, renders the region, or — failing both — the whole buffer.  =C-u C-c C-x C-l= re-renders the buffer from cache; =C-u C-u C-c C-x C-l= regenerates (recompiles) it.  =M-x org-latex-to-svg-refresh= re-tints / re-scales for the current theme and font size straight from cache (no LaTeX).

Three things to try as you read:

- *Move point into any preview* — it reveals the LaTeX source for editing; move out and it re-shows the image (or re-renders if you changed the text).
- *Click a reference* like the =(1)= below (=mouse-1= or =RET=) — it jumps to the equation that defines the label.
- *Edit a numbered equation* (e.g. delete one, or turn =equation= into =equation*=) — every number below, and every reference, updates a moment later on its own.

* Inline math

The mass–energy relation is $E = mc^2$, and Euler's identity $e^{i\pi} + 1 = 0$
is often called the most beautiful equation in mathematics.  A quadratic
$ax^2 + bx + c = 0$ has roots \( x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \).

Inline previews scale with the surrounding font, so a text-zoom
(=C-x C-+=) rescales them from cache with no recompile.

* Unnumbered display math

A centered display equation with =\[ … \]= consumes no equation number:

\[ \int_{-\infty}^{\infty} e^{-x^2}\, dx = \sqrt{\pi} \]

* Automatic equation numbering

Numbering is on by default (=org-latex-to-svg-number-equations=).  The number is
computed from the equations that precede each block and baked into the render,
so these come out as =(1)=, =(2)=, … in document order:

#+begin_comment
Note: the numbers below are computed live; the labels let the references resolve.
#+end_comment

\begin{equation}
\label{eq:newton}
\mathbf{F} = m\mathbf{a}
\end{equation}

Maxwell's equations number *per row* — each line gets its own number:

\begin{align}
\label{eq:gauss-e}
\nabla \cdot \mathbf{E} &= \frac{\rho}{\varepsilon_0} \\
\nabla \cdot \mathbf{B} &= 0 \\
\nabla \times \mathbf{E} &= -\frac{\partial \mathbf{B}}{\partial t} \\
\nabla \times \mathbf{B} &= \mu_0 \mathbf{J} + \mu_0 \varepsilon_0 \frac{\partial \mathbf{E}}{\partial t}
\end{align}

\begin{equation}
\label{eq:schrodinger}
i\hbar \frac{\partial}{\partial t}\,\Psi(\mathbf{r}, t) = \hat{H}\,\Psi(\mathbf{r}, t)
\end{equation}

* Cross-references

References resolve to the real number and render as plain buffer text (matching
the prose font), and each is click-to-jump:

- Newton's second law is \eqref{eq:newton}.
- Gauss's law for \(\mathbf{E}\) is \eqref{eq:gauss-e}, the first row of the
  Maxwell block.
- The time-dependent Schrödinger equation is \eqref{eq:schrodinger}.

A bare =\ref= gives just the number: see \ref{eq:schrodinger}.

* Partial numbering, starred, and multline

Only some rows of an =align= need numbers — mark the rest =\nonumber=:

\begin{align}
a &= b + c \nonumber \\
  &= d \label{eq:result}
\end{align}

Result \eqref{eq:result} is the only numbered line above.

A starred environment is never numbered and doesn't advance the counter:

\begin{equation*}
\oint_{\partial S} \mathbf{B} \cdot d\boldsymbol{\ell} = \mu_0 I_{\text{enc}}
\end{equation*}

A =multline= is a *single* number spanning several lines (its =\\= are line
breaks, not new equations):

\begin{multline}
(a + b + c + d + e)^2 = a^2 + b^2 + c^2 + d^2 + e^2 \\
+ 2ab + 2ac + 2ad + 2ae + 2bc + 2bd + 2be + 2cd + 2ce + 2de
\end{multline}

* Matrices and nested structures

Line breaks inside a nested environment (=pmatrix=, =cases=, …) are not counted
as equation rows, so the numbering of a surrounding =align= stays correct:

\[ \sigma_x = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}, \quad
   \sigma_y = \begin{pmatrix} 0 & -i \\ i & 0 \end{pmatrix}, \quad
   \sigma_z = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix} \]

\begin{align}
\lvert \psi \rangle &= \begin{pmatrix} \alpha \\ \beta \end{pmatrix} \\
\lvert x \rvert &= \begin{cases} x & x \ge 0 \\ -x & x < 0 \end{cases}
\end{align}

* A summation and a limit

\[ \sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}, \qquad
   \lim_{x \to 0} \frac{\sin x}{x} = 1 \]
